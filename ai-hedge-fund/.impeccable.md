## Design Context

### Users
A single investor doing equity research at a desk — the person who also built the
tool. Sessions are deliberate rather than reactive: reading a thesis, checking
whether the numbers behind it hold, deciding what to do. Not a trading terminal,
not a consumer app.

### Brand Personality
Mechanical, contrarian, exacting. The product's whole argument is that a language
model should not be trusted with arithmetic, so the interface has to look like it
shows its work rather than like it is selling confidence.

### Aesthetic Direction
Jackson Pollock's drip canvases: unbleached linen with household enamel thrown at
it — oxide red, cadmium yellow, cobalt, aluminium, and a great deal of black. The
excitement is in density and collision, not saturation.

- **Landing** (`/`): raw canvas ground, heavy paint, display type at scale.
- **App**: the same palette under studio dark — warm ink, not slate — so the two
  read as one hand.
- **Display/labels/numerals**: Departure Mono (Helena Zhang, SIL OFL). A 1-bit
  pixel face: whole-pixel sizes only, smoothing off, never used for prose.
- **Body**: Bricolage Grotesque.

Anti-references: cyan-on-black dashboards, glassmorphism, neon-on-dark "fintech",
gradient text, card grids of identical boxes.

### Design Principles
1. **Show the work.** Computed values, provenance and verification are primary
   content, not disclosure panels.
2. **Paint is ground, type is figure.** Density never wins against legibility —
   prose gets a canvas label when it sits over paint.
3. **Colour is assigned, not decorative.** Each section and each status holds one
   hue from the palette so hue carries meaning.
4. **Limitations get equal weight to features.** A research tool that oversells
   its certainty is worse than one that states what it cannot do.
5. **The pixel face is a label face.** Departure Mono for display, labels and
   numerals; never for a paragraph.
